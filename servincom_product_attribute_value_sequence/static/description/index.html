Orden global de valores de atributos

Odoo Community 18.0 · SERVINCOM SOLUCIONES · Licencia AGPL-3.

Arrastre los valores desde Atributos y variantes → Configurar. El orden se comparte entre todos los productos que utilizan esos valores.

  • Control de arrastre y campo Secuencia global.
  • Combinaciones ordenadas al abrir el botón Variantes.
  • Los selectores web estándar utilizan la misma secuencia.

Las variantes conservan sus identidades. Las personalizaciones de la web que impongan otro orden requieren validación específica.

Documentación, instrucciones de instalación y pruebas en README.rst.
